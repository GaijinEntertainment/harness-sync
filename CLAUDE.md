# cc-sync

cc-sync syncs the Claude Code user-level setup between machines through a git repo. Each machine pushes its own changes
and pulls the changes of the others; no machine is the master. The design is in `design-docs/`.

## Vocabulary

- Name every concept with its term from `docs/glossary.md`. Never use a name that an **Avoid** line of the glossary
  lists.
