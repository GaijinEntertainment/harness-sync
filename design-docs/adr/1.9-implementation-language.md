# Write cc-sync in Rust

- **Date:** 2026-11-06
- **Governs:** `/`
- **Implementation:** pending — the release workflow has not run, because the GitHub repo does not exist yet

cc-sync runs first on a new machine, an agent reads its JSON reports, and its core is a three-way comparison of JSON
items. cc-sync is written in Rust and ships as one native binary per platform. Each platform builds on its own CI
runner.

## Decision

- **Rust.** cc-sync is written in Rust.
- **Native binaries.** cc-sync ships as one binary per platform for Linux, macOS, and Windows, built by a GitHub
  Actions matrix of native runners. The binary needs no language runtime on the target machine.

## Why

- A machine set up with the native Claude Code installer can lack Node, and cc-sync runs first on a new machine.
- cc-sync has no TUI ([1.8](/design-docs/adr/1.8-operator-interface.md)), so no TUI library decides the language.
- An agent reads the JSON reports. `serde` derives them from typed values, item states included.
- The item states of the three-way comparison ([1.3](/design-docs/adr/1.3-concurrent-changes.md)) are a Rust enum, and
  a `match` that misses a state does not compile.
- Claude Code wrote `settings.json` and `~/.claude.json` as two-space JSON on the reference machine (2026-11-06).
  `serde_json` with `preserve_order` and `arbitrary_precision` round-trips that format, and `jsonc-parser` with its
  `cst` feature edits a value in place ([1.6](/design-docs/adr/1.6-target-file-writes.md)).

## Consequences

- Rust builds are slower than Go builds in an edit-and-test loop. Accepted.
- Each platform needs its own CI runner instead of a cross-compilation from one machine. Accepted.

## Rejected

- **Go** — cross-compiles from one machine, but its standard library has no order-preserving map, `encoding/json`
  escapes `&`, `<`, and `>` by default, and a `switch` that misses a state compiles.
- **Node** — a machine set up with the native Claude Code installer can lack Node.

## Revisit if

A required platform has no Rust target or no CI runner. Confidence: high.
