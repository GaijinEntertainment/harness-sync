# Run git operations through the git executable

- **Date:** 2026-11-06
- **Governs:** `/`, `cc-sync init`, `cc-sync push`, `cc-sync pull`
- **Implementation:** pending — no code exists yet (not scheduled)

The repo can be on any git remote, and the user already has git authentication for it. cc-sync runs every repo operation
through the `git` executable on PATH. `git` must be installed on every machine.

## Decision

- **git executable.** cc-sync runs clone, fetch, commit, and push through the `git` executable on PATH, in the local
  clone under `~/.cc-sync/`. cc-sync embeds no git library.

## Why

- The brief: the repo is on any git remote. The `git` executable already uses the SSH keys, agents, credential helpers,
  and host configuration of the user for it.

## Consequences

- `git` must be on PATH, also on Windows, where Claude Code does not require Git for Windows. Accepted.

## Rejected

- **An embedded git library** — must implement SSH agent, credential-helper, and host-configuration support again to
  reach the same remotes.

## Revisit if

A target platform cannot have the `git` executable. Confidence: high.
