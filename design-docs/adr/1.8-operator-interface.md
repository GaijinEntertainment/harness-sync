# Build a CLI that an agent can operate without a TTY, and no TUI

- **Date:** 2026-11-06
- **Governs:** `/`, `cc-sync init`, `cc-sync status`, `cc-sync push`, `cc-sync pull`
- **Implementation:** pending — the secret scan exit code and the masking of secret values in the output are not built
  (frame Phase 2)

A human runs the first installation of cc-sync, and an LLM agent runs the later commands through a shell. cc-sync is a
plain command-line program: every command completes without a TTY, every prompt has a flag that replaces it, and every
report has a JSON form. A human gets plain line prompts, not a navigable interface.

## Decision

- **No TUI.** cc-sync has no full-screen or event-loop terminal interface.
- **No TTY needed.** Every command runs to completion without a TTY. A prompt appears only when stdin and stdout are a
  TTY, and a flag replaces each prompt, including the choice of a side for one conflict.
- **JSON reports.** `status`, `push`, and `pull` print their item lists as JSON with `--json`. The JSON shape is a
  contract: a change to it is a breaking change of cc-sync.
- **Exit codes.** Each outcome that an operator acts on has its own exit code: success, a pull stopped on conflicts, a
  push refused because the remote is ahead, a push blocked by the secret scan, a usage error, and any other failure.
- **No secret in output.** No output of cc-sync, text or JSON, contains a secret value.

## Why

- The user: terminal UIs have been hard to support and had many bugs in the user's experience.
- The user: a human does the first installation, and an agent does all later calls through the CLI. An agent runs
  commands without a TTY and reads output as text.

## Consequences

- A human picks conflict sides in sequential line prompts, not in a list with navigation. Accepted.
- The JSON shape cannot change freely once agents depend on it. Accepted.

## Rejected

- **A TUI** (Bubble Tea, ratatui) — the user's experience: hard to support and buggy.
- **Prompt-only conflict and secret handling** — an agent without a TTY cannot answer a prompt.

## Revisit if

A human becomes the main operator of the later commands. Confidence: high.
